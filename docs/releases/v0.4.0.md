# Cockpit v0.4.0

This release makes the agentic SDLC planner work on large monorepos: several Cargo
workspaces, one Bun workspace and Moon projects. It was tried on a real monorepo
with ten Cargo workspaces.

## New

- **Merge-base diffs:** `plan --base REF` and `verify --base REF` diff from
  `git merge-base REF HEAD`, so changes the base gained after the branch point are
  no longer reported as the branch's own. A fixed ancestor SHA behaves as before.
- **Path classes** in `[development]`: `test_data` (fixtures, testdata, snapshots,
  proptest regressions by default) plans the owning project's tests; `generated`
  plans that project's checks, tests and dependents; `documentation` plans nothing;
  `test_inputs` maps a file to the projects whose tests read it. A root lockfile or
  manifest plans every Moon project of its language. Anything unclassified still makes
  the scope unknown (fail-closed).
- **Languages from `moon.yml`:** tags first, then `language`, then the presence of
  `Cargo.toml`/`package.json`, instead of file extensions.
- **Downstream expansion:** `--downstream none|direct|deep` (or
  `[development] downstream`) follows `dependsOn` in each `moon.yml` backwards. Off by
  default; it reads the project files and never runs `moon query`, so planning stays
  read-only.
- **Per-crate edit checks:** Blaze/Cargo edit checks run in the changed crate's own
  Cargo workspace with `-p <crate>`; a workspace manifest or lockfile gets
  `--workspace`, a changed test adds `--all-targets`. These advisory checks are offered
  even when the scope is unknown.
- **`--policy FILE`:** `plan` and `verify` read `[development]` from another
  `cockpit.toml`, for worktrees without their own config.
- The plan JSON gains `downstream`, `downstream_projects`, `path_classes` and `notes`
  (additions only).

## Compatibility and limitations

- Additive: existing commands, config and JSON fields behave as in v0.3.0 unless the
  new keys or flags are used, except that `--base` now diffs from the merge base.
- Impact mapping is still path-based, not compiler-resolved; downstream expansion
  follows declared Moon dependencies only. Blaze stays advisory; Cargo and existing CI
  remain authoritative.
- ADR-0016 is amended; FEAT-013, `docs/cli.md`, `docs/config.md` and
  `docs/agentic-sdlc.md` describe the new behaviour.

## Installation

Download the binary for your platform from the
[GitHub release](https://github.com/drietsch/cockpit/releases/tag/v0.4.0).
Verify it against `SHA256SUMS`. See [README](../../README.md) and
[agentic SDLC guide](../agentic-sdlc.md) for configuration.
