# Cockpit v0.5.0 (draft notes)

## New

- **`source_config` path class** in `[development]`: hand-written project configuration
  (bundle `manifest.json`, `moon.yml` by default) belongs to its owning Moon project and plans
  that project's checks and tests, plus dependents under `downstream`, like a source file.
  Before, such a file was `unknown` and the whole plan proposed no actions.
- A listed `source_config` replaces the defaults (`[]` turns it off). Root configuration
  (`.github/`, `.moon/`, `tooling/`) and files outside every project stay `unknown`.
- The plan JSON `path_classes` gains `source_config` (additive).

ADR-0016 is amended; FEAT-013, `docs/cli.md`, `docs/config.md` and
`docs/agentic-sdlc.md` describe it.
