# Cockpit v0.3.0

This release introduces an **experimental agentic SDLC subsystem** while keeping
Cockpit's existing evidence-based feature health model unchanged.

## New

- **`cockpit plan`**: read-only staged change-impact guidance for Rust and
  TypeScript, with Moon/Cargo/Bun project ownership, bounded JSON responses,
  and explicit unknown-scope reporting.
- **`cockpit verify`**: opt-in execution of selected checks and tests with
  compact outcomes and local log files. Optional Blaze preflights are advisory;
  pinned Cargo and existing CI gates remain authoritative.
- **Playwright selection**: connect changed paths to existing feature-to-test
  evidence, selecting and deduplicating exact spec files for fast edit feedback.
  This is not exhaustive code coverage or a substitute for browser CI.
- **`cockpit usage`**: aggregate local Claude Code session token usage by model
  (input/output/cache reads/cache creation), plus observed session spans.
  No prompts, tool output, or session IDs are exported; no costs are guessed.
- **Shared local/CI policy** in `[development]` of `cockpit.toml`.
- New agentic SDLC documentation, proposed ADR-0016, and FEAT-013.

## Also included since v0.2.1

- Correctly disregard Playwright project suffixes as feature references.
- Improve claim honesty and stale/removed citation validation.

## Compatibility and limitations

- The new commands are opt-in. Existing `status`, `scan`, `serve`,
  `validate`, and evidence import workflows are preserved.
- Impact mapping is path/feature-based, not compiler-resolved. Test selection
  is advisory; unknown dependencies and specialized CI gates still need
  appropriate checks.
- Blaze is never considered authoritative; Cargo remains required in CI.
- Per-task token/latency improvements have **not yet been benchmarked**.
- The agentic subsystem remains experimental in v0.3.0.

## Installation

Download the binary for your platform from the
[GitHub release](https://github.com/drietsch/cockpit/releases/tag/v0.3.0).
Verify it against `SHA256SUMS`. See [README](../../README.md) and
[agentic SDLC guide](../agentic-sdlc.md) for configuration.
